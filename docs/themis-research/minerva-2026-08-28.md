## Improvements the open spec must take

Keep the law. Do not copy `prompt.md` as the spec.

1. **Data adapters.** `data.source`: `csv` | `vision` | `ccxt`. Vision = Binance USD-M monthly kline zips. Cache path can stay `research/.cache/<provider>/<exchange>/<symbol>/<tf>.csv`. A desk that is geo-blocked must still `ask` from CSV/Vision.
2. **Per-series windows.** Each spec records `discovery` / `holdout` that fit bars actually loaded, plus `actual_start`, `actual_end`, `n_bars` on the run. Default holdout is a tail fraction of available bars, not a calendar year that does not exist. Gold 4h Vision starts 2025-12 (~8 months). SPY/QQQ 4h start 2026-04 (~4 months). BTC/SOL 4h can prove 2022+.
3. **Rival asks first-class.** Vague English becomes 2–4 explicit question YAMLs, each with its own run folder. Prometheus's CSV trial: same 75% English, bounce rate moved 11 points across definitions. Strategy YAML cites those folders. Do not quiz Amir for impulse/bounce/stop.
4. **YAML before compiler.** Ship schemas + CLI (`fetch`, `ask`, then later `run`) that run offline from files. English → YAML is last mile, not week one. No skill package this pass.
5. **Gold is the go-live conversation, not the long-window proof.** R1 on XAUUSDT 4h is an 8-month `ask`. Small n. Kill `min_trades: 30` will likely fail; the spec must not copy that number onto gold. BTC/SOL prove long discovery/holdout. Do not claim a 3-year gold test.
6. **`run` engine limits.** Keep `backtesting.py` for v1. It has no perp funding. 4h SL/TP from OHLC is optimistic. Costs are a written placeholder (`0` only with a reason). Reports must list these as not execution-ready. Net return is not a live claim.
7. **Identity.** Provider `binance`, symbol, ccxt/Vision exchange id (`binanceusdm` for these perps). Never merge venues or substitute `XAUT` / `PAXG` / `GC=F` / e-minis.
8. **Promotion.** `ask` → discovery `run` → one `validate` on locked holdout → kept. Indicator/alert after kept. Paper and live are never implied.
